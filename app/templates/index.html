Process

How It Works

Three simple steps from URL to prediction.

01

Paste a URL

Enter any link you want to verify in the scanner above. No sign-up required.

02

Feature Extraction

The system automatically extracts 15 structural and lexical characteristics from the URL — length, subdomains, HTTPS usage, character ratios, and more.

03

ML Prediction

A trained HistGradientBoosting classifier evaluates the extracted features and returns a prediction with a confidence score.

Model Information

Our detection system uses a HistGradientBoosting Classifier trained to distinguish phishing and legitimate URLs based on lexical and structural URL patterns..

Limitation: The model evaluates structural patterns in a URL. It does not inspect the actual content, reputation, or live behavior of the destination website. A well-disguised URL may still be classified incorrectly.
